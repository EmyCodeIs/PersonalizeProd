CORREÇÕES SEGURAS APLICADAS

1. brace-expansion
- Versão anterior: 1.1.16.
- Versão corrigida: 1.1.18.
- Origem: rimraf → glob → minimatch → brace-expansion.
- Risco corrigido: expansão sem limite capaz de causar negação de serviço por consumo de memória.
- Forma da correção: npm override mantendo a mesma linha principal da dependência.

2. ip-address
- Versão anterior: 10.2.0.
- Versão corrigida: 10.4.0.
- Origem: Puppeteer → proxy-agent → socks-proxy-agent → socks → ip-address.
- Risco corrigido: interpretações ambíguas de endereços capazes de contornar verificações de SSRF e limites de confiança.
- Forma da correção: npm override mantendo a versão principal 10.

VULNERABILIDADES AINDA PENDENTES

1. @wppconnect-team/wppconnect
- Severidade agregada: alta.
- É reportada porque depende de file-type, latest-version e sharp vulneráveis.
- O npm informa que não existe correção automática disponível.

2. sharp 0.34.5 interno do WPPConnect
- Severidade: alta.
- O projeto já utiliza sharp 0.35.3 diretamente.
- O WPPConnect fixa exatamente sharp 0.34.5 dentro do próprio pacote.
- Um override foi testado, mas o npm manteve a instalação interna como inválida, sem substituir corretamente o pacote.
- Não foi forçada a troca para evitar quebrar processamento de QR, imagens ou mídias.

3. file-type 16.5.4
- Severidade: moderada.
- Risco: loop infinito ao analisar arquivo ASF malformado.
- Correção upstream exige versão 21.3.1 ou superior.
- O WPPConnect fixa a linha 16.5.x.
- A atualização exigiria salto grande de API e possível migração de CommonJS para ESM.

4. latest-version 5.1.0
- Severidade: moderada.
- A vulnerabilidade é herdada de package-json.
- A versão atual segura disponível está várias versões principais à frente.
- O WPPConnect continua declarando latest-version 5.1.x até em sua versão mais recente.

5. package-json 6.5.0
- Severidade: moderada.
- A vulnerabilidade é herdada de got 9.6.0.
- A correção exige atualização principal incompatível com a árvore atual.

6. got 9.6.0
- Severidade: moderada.
- Risco: redirecionamento para socket UNIX.
- A correção disponível exige got 11.8.5 ou superior.
- package-json 6.5.0 depende da API antiga do got 9.

POR QUE O WPPConnect NÃO FOI APENAS ATUALIZADO

A versão instalada resolvida pelo lock era 2.2.3.
A versão mais recente consultada era 2.2.6.

Mesmo a versão 2.2.6 ainda declara:

- latest-version ^5.1.0;
- sharp 0.34.5.

Portanto, atualizar apenas o WPPConnect não elimina as seis vulnerabilidades restantes.
